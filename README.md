# Terraform Learning Journey

Welcome to my Terraform learning repository! 👋

This repository documents my journey of learning **Terraform** by following **Shubham Sharma's Terraform One-Shot** course. As I progress, I'll be adding practice exercises, examples, notes, and small projects to reinforce my understanding of Infrastructure as Code (IaC).

## About This Repository

The purpose of this repository is to:

* Learn Terraform concepts through hands-on practice.
* Keep track of my learning progress.
* Experiment with Terraform features and workflows.
* Build a collection of reusable examples for future reference.
* Strengthen my understanding of Infrastructure as Code.

## What You'll Find

This repository includes practice on topics such as:

* Terraform Basics
* Providers
* Resources
* Variables
* Outputs
* Locals
* Data Sources
* Functions & Expressions
* State Management
* Remote Backends
* Modules
* Provisioners
* Workspaces
* Lifecycle Meta Arguments
* Best Practices
* Mini Projects

## Terraform Workflow

```bash
terraform init
terraform fmt
terraform validate
terraform plan
terraform apply
terraform destroy
```
